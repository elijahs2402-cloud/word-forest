# Word Forest icon assets

Menu artwork is original SVG in `src/MenuIcon.tsx`, inspired by the bold silhouettes, separate colors and playful shallow depth of the Duolingo navigation reference: https://mobbin.com/screens/02544e61-aefd-4d89-815e-ffcc83d83539

The app icon retains the original Mongshell front-view face. Only crop, resize and composition are applied; no AI face rendering is used. The built-in image generation tool created the background only. Outputs: `public/art/mongshell-app-icon.png` and `public/mongshell-icon-{32,192,512}.png`.

## Background generation prompt

Use case: logo-brand. Asset type: background-only tile for an original children's vocabulary forest app icon. Create one square 1024x1024 edge-to-edge vivid fresh leaf-green background, subtle flat playful rounded geometric leaf silhouettes softly embossed near outer corners only. Center and central 80 percent entirely empty uniform bright green to receive a separately composited real plush face. Clean bold vector-like aesthetic, crisp, premium, lively educational game. No mascot, no face, no letters, no owl, no logo, no border, no outer rounded clipping, no shadow outside the tile. Avoid detailed scenery or realistic texture. Large legible simple shapes. This is an original forest app, not a Duolingo reproduction.
