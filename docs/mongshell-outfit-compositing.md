# 몽쉘 의상 제작 공통 기준

## 원본 보존

- 베이스: `public/art/mongshell-v3/base.png`.
- 베이스의 색상·형태·픽셀 크기·위치·1000×1000 캔버스와 투명 여백을 바꾸지 않는다.
- 전체 몽쉘을 AI로 재생성하지 않는다. AI가 만드는 대상은 의상뿐이다.
- 최종 결과는 원본 베이스 위에 별도 의상 RGBA 레이어를 source-over 합성한다.
- 의상이 덮지 않는 픽셀은 원본과 동일한지 검증한다.

## 피팅과 털 경계

- 승인된 피팅 기준: 사용자가 포토샵에서 작업한 `O-references/hood-strawberry.png`.
- 목·겨드랑이·밑단에 원본 털 경계를 조금 포함하여 의상이 자연스럽게 이어지도록 한다.
- 포함된 털만 바깥쪽으로 갈수록 점차 투명해지게 한다. 안쪽 털은 유지한다.
- 원단·봉제선·옷 밑단·끈·자수에는 털 페이드를 적용하지 않는다.
- 털 전체의 불투명도를 일괄 낮추거나 경계를 잘라내지 않는다. 밑단이 잘려 보이거나 딱딱한 선, 갈색 띠, 빈 틈이 생기지 않도록 한다.
- 끈 구멍이나 갈색 덧댐 덩어리를 만들지 않는다.
- 이 기준은 레몬 후드를 포함해 앞으로 제작하는 모든 의상에 적용한다.

## 산출물과 확인

- 별도 투명 의상 레이어와 최종 합성 PNG를 모두 보관한다.
- 원본과 이전 승인본은 덮어쓰지 않고 버전 파일을 추가한다.
- 레이어를 대비되는 배경에 놓아 목·겨드랑이·밑단을 확대 확인하고, 원본 위의 실제 합성 결과도 확인한다.
- 채팅에는 실제 저장한 합성본을 보여 준다. AI 의상 생성 원본과 최종 합성본을 혼동하지 않는다.
- 앱 적용·커밋·배포는 별도 요청이 있을 때 진행한다.
