# Approved six hoodies release

Six fruit hoods use original-base composites, not regenerated characters. Stable item IDs, clothing-only catalog thumbnails, saved outfit/forest data, and other body costumes are unchanged.

The release manifest `public/art/mongshell-v3/hood-release-v1.json` selects strawberry furfade v2, blueberry furfade v4, and lemon/pear/grape/peach Photoshop composites v1. Each original 1000-square composite and separate clothing layer is preserved.

Runtime copies use the established 551x670 character viewport, extracted at (225,175) from the 1000-square masters without resizing any visible pixels. This preserves existing rendering and accessory placement. The user's locally edited 1000-square base.png is not overwritten or included in this six-hood-only release; deployed base/other poses remain unchanged.

Only the six hoodie mappings change. Full assets, layers and runtime copies are tracked explicitly; experiments, other clothing, audio drafts and local configuration are excluded.
